# CSM App — versão alpha (web)

Build compilado do aplicativo do **Campeonato San Marino**, publicado para avaliação
interna da equipe administrativa.

- **Acesse:** https://hugocarneiro-box.github.io/csm-app-alpha/
- Alpha: em avaliação, sujeito a mudanças.
- Este repositório contém **apenas o artefato compilado** (saída de `flutter build web`).
  O código-fonte é privado.
- Os dados exibidos são pseudonimizados: a superfície pública do app não mostra nome
  real de piloto.

Publicado a partir do repositório privado `san-marino-app`, branch `fases-def-app`.
