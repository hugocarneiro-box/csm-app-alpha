# CSM App — versão alpha (web)

Build compilado do aplicativo do **Campeonato San Marino**, publicado para avaliação
interna da equipe administrativa.

- **Acesse:** https://hugocarneiro-box.github.io/csm-app-alpha/
- Versão de AVALIAÇÃO (modo alpha): nenhuma tela fica bloqueada. As áreas ainda travadas
  por parecer jurídico ou decisão fiscal abrem em modo DEMONSTRAÇÃO, com selo visível e
  dados de exemplo (nomes fictícios).
- Este repositório contém **apenas o artefato compilado**. O código-fonte é privado.
- Os dados reais exibidos são pseudonimizados: a superfície pública do app nunca mostra
  nome real de piloto.
